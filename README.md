# PackCheck

PackCheck — учебный FastAPI-сервис для проверки состава и веса снаряжения для велопохода. Он помогает велотуристу посмотреть список вещей, узнать общий вес и проверить, укладывается ли набор в заданный лимит.

Проект курса «Инфраструктура и администрирование» образовательной программы «Прикладные нейросетевые технологии» НИУ ВШЭ.

В приложении используется демонстрационный набор из 9 вещей общим весом 8400 г (8.4 кг). Самый тяжёлый предмет — вода, 2500 г. Список хранится в `app_final.py`; изменение списка через API не предусмотрено.

## Требования

- Linux и терминал Bash.
- Python 3.14 с модулями `venv` и `pip`.
- Git для клонирования репозитория.

Локальные проверки выполнены на Ubuntu 26.04.1 LTS с Python 3.14.4. В GitHub Actions используется Python 3.14.

## Установка

Выполните в терминале:

```bash
git clone https://github.com/karkankat/Packcheck.git
cd Packcheck
python3.14 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

`requirements.txt` содержит зависимости для запуска. `requirements-dev.txt` содержит полный список библиотек окружения с инструментами тестирования и зафиксированными версиями.

При открытии нового терминала перейдите в папку проекта и снова активируйте окружение:

```bash
source .venv/bin/activate
```

## Запуск

Из папки проекта с активированным окружением выполните:

```bash
python -m uvicorn app_final:app
```

Это команда для обычного запуска без `--reload`.

Откройте в браузере:

- [Главную страницу](http://127.0.0.1:8000/).
- [Интерактивную документацию API](http://127.0.0.1:8000/docs).
- [Проверку работоспособности](http://127.0.0.1:8000/health).
- [Версию приложения](http://127.0.0.1:8000/version).

Если приложение запущено внутри виртуальной машины, эти адреса открывайте в браузере той же виртуальной машины. Адрес `127.0.0.1` указывает на компьютер, на котором открыт браузер.

Для остановки приложения нажмите `Ctrl+C` в терминале запуска.

## Маршруты API

Все перечисленные маршруты используют метод GET и возвращают JSON.

| Маршрут | Назначение |
|---|---|
| `/` | Сообщение о работе PackCheck и путь к документации |
| `/health` | Проверка работоспособности: `{"status":"ok"}` |
| `/version` | Версия приложения: `{"version":"0.3.0"}` |
| `/items` | Все вещи и их количество |
| `/items?category=sleep` | Фильтрация вещей по категории |
| `/summary` | Количество вещей, общий вес в граммах и килограммах, самый тяжёлый предмет |
| `/check?limit_kg=10` | Проверка общего веса относительно лимита в килограммах |

Категории: `sleep` — ночлег, `repair` — ремонт, `clothes` — одежда, `supplies` — вода и еда. Неизвестная категория возвращает пустой список и `item_count: 0`.

Примеры запросов:

- [Снаряжение для ночлега](http://127.0.0.1:8000/items?category=sleep).
- [Сводка веса](http://127.0.0.1:8000/summary).
- [Проверка лимита 10 кг](http://127.0.0.1:8000/check?limit_kg=10): набор подходит, запас 1.6 кг.
- [Проверка лимита 8 кг](http://127.0.0.1:8000/check?limit_kg=8): набор превышает лимит на 0.4 кг.

При весе, равном лимиту, `fits` равно `true`.

## Настройка лимита через окружение

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `DEFAULT_WEIGHT_LIMIT_KG` | `10` | Лимит веса в килограммах для `/check` без параметра `limit_kg` |

Запуск с лимитом по умолчанию 8 кг:

```bash
DEFAULT_WEIGHT_LIMIT_KG=8 python -m uvicorn app_final:app
```

Откройте [проверку без параметров](http://127.0.0.1:8000/check). Ответ:

```json
{
  "total_weight_kg": 8.4,
  "limit_kg": 8.0,
  "fits": false,
  "remaining_kg": 0.0,
  "overweight_kg": 0.4
}
```

Параметр запроса имеет приоритет: `/check?limit_kg=10` проверит лимит 10 кг даже при настройке окружения `8`. Если параметр и переменная окружения отсутствуют, используется 10 кг.

Лимит должен быть положительным конечным числом с точностью до 0.001 кг. Для дробных чисел используется точка, например `8.5`. Некорректный параметр запроса вызывает ответ HTTP 422. Некорректная переменная окружения вызывает понятную ошибку при запуске.

Настройка читается при запуске приложения; после её изменения приложение нужно перезапустить. Запись перед командой запуска действует только для этой команды.

Файл `.env.example` показывает пример настройки. Приложение не загружает файлы `.env` автоматически: значение передаётся через окружение процесса. Настоящий `.env` исключён из Git через `.gitignore`.

## Автоматические тесты

В активированном окружении из папки проекта выполните:

```bash
python -m pip install -r requirements.txt -r requirements-dev.txt
python -m pytest -v
```

Ожидаемый результат — `18 passed`.

Тесты проверяют `/health`, `/version`, список и фильтрацию вещей, неизвестную категорию, расчёт общего веса, лимиты выше, ниже и на границе веса, недопустимые значения, настройку через окружение, приоритет параметра запроса и запись результата в лог.

Используется `TestClient`: отдельный запуск Uvicorn для тестирования не требуется.

## GitHub Actions и артефакт

Workflow находится в `.github/workflows/ci.yml`. Он запускается при `push`, `pull_request` и вручную через `workflow_dispatch`.

1. Задание `test` устанавливает Python 3.14, зависимости и запускает `python -m pytest -v`.
2. После успешных тестов задание `package` создаёт артефакт `packcheck-project` с файлами проекта. Зависимость заданий указана через `needs: test`.

Результат доступен на странице [PackCheck CI](https://github.com/karkankat/Packcheck/actions/workflows/ci.yml). Откройте нужный запуск и раздел Artifacts для скачивания архива. Срок хранения артефакта — 30 дней.

В артефакт включаются только явно перечисленные в workflow файлы: код, тесты, зависимости, README, `.env.example`, `.gitignore` и настройка CI.

## Логи и диагностика

Логи видны в терминале, где запущено приложение. При запуске PackCheck выводит версию и выбранный лимит, а при обращении к `/check` — общий вес, лимит и результат сравнения. Uvicorn дополнительно выводит адреса запросов и коды ответов.

Пример сообщения о результате:

```text
INFO packcheck: Проверка веса: total_kg=8.400 limit_kg=8.000 fits=False
```

Для проверки работы откройте `/health`: ожидается HTTP 200 и `{"status":"ok"}`. Маршрут `/version` должен вернуть HTTP 200 и `{"version":"0.3.0"}`.

| Ситуация | Что проверить или сделать |
|---|---|
| Браузер не подключается | Проверьте, что Uvicorn продолжает работать в терминале и открыт правильный адрес и порт |
| `No module named uvicorn` или `fastapi` | Активируйте `.venv` и установите зависимости из `requirements.txt` |
| `No module named pytest` | Установите зависимости из `requirements-dev.txt` |
| `Could not import module "app_final"` | Выполняйте запуск из папки с файлом `app_final.py` |
| `Address already in use` | Остановите ранее запущенный экземпляр через `Ctrl+C` в его терминале или используйте другой порт |
| HTTP 422 на `/check` | Укажите положительный конечный лимит с точностью до 0.001 кг; дробная часть отделяется точкой |
| Ошибка с `DEFAULT_WEIGHT_LIMIT_KG` при запуске | Исправьте значение переменной; для удаления ранее экспортированного значения выполните `unset DEFAULT_WEIGHT_LIMIT_KG` |

Запуск на другом порту:

```bash
python -m uvicorn app_final:app --port 8001
```

В этом случае документация доступна по адресу `http://127.0.0.1:8001/docs`.
