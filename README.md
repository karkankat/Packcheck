# PackCheck

Учебный FastAPI-сервис для проверки состава и веса снаряжения для велопохода

Планируемые возможности:
- /items - просмотр снаряжения и фильтрация по категории.
- /summary - общий вес, количество вещей и самый тяжёлый предмет.
- /check - проверка соответствия заданному лимиту веса.

Проект курса "Инфраструктура и администрирование"
